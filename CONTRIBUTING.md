
# Contributing

Use the Windows setup script, run the tests and format Python changes with Ruff. Keep evidence samples synthetic and compact. Add regression coverage around source anchors, evidence integrity, case permission changes, and sensitive exports. For schema updates create a new Alembic revision and verify an upgrade from the previous revision. Update supported formats and limitations in the investigator guide when changing parser behavior.

Use descriptive commit messages. Keep environment files, passwords, local databases, private evidence and unrelated generated artifacts out of Git. Commit measured research files with their reproducibility configuration. Use documentation addresses for samples and identifiers.
